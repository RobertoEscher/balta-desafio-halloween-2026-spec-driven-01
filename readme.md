## 🎃 Halloween - Desafio 1

Oi, eu sou o Roberto Escher e este é o espaço onde compartilho minha jornada de aprendizado durante o desafio **Halloween 2026**, realizado pelo [balta.io](https://balta.io). 👻

Aqui você vai encontrar projetos, exercícios e códigos que estou desenvolvendo durante o desafio.

### Sobre este desafio
Neste desafio o objetivo é consolidar os fundamentos do Spec Driven Development, criando uma constituição, especificação, planejamento e tarefas manualmente para serem implementadas pela IA posteriormente.

#### O que foi implementado
- Minimal API em C# .NET 10
- Implementação com uso de Blazor Server
- Banco de dados SQLite
- Geração de endpoints para teste via CRUD

Neste processo eu aprendi:
* ✅ Criar os artefatos .md do SDD manualmente
* ✅ Excutar a clarificação para possíveis correções
